Terms of use

Effective date: 3 October 2026. Les Sherpas Work Sync is a personal scheduling tool maintained by Tomas Delon. It is provided for use with accounts and calendars the operator is authorized to access.

Scope

The application reads lesson records and creates or updates their calendar representations. It does not book, confirm, cancel or pay for lessons on Les Sherpas. Calendar entries are a convenience; the source platform remains authoritative for bookings.

Operating requirements

The owner must keep the computer, local user session, network, authentication and durable private state available. Access may stop if a provider revokes authorization or changes its interfaces. Any synchronization failures or ambiguous statuses require review. The application cannot guarantee uninterrupted service or that every hidden source record is exposed.

Protected records

The application does not delete calendar events or automatically modify unrelated manual events. Persistent suppression records prevent automatic recreation of manually removed synchronized lessons. Restoring a suppressed lesson requires a specific owner action.

Contact

Questions can be directed through the maintainer’s contact page. See the privacy policy for data handling.
