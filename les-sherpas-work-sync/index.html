Les Sherpas Work Sync

An independent personal scheduling tool maintained by Tomas Delon. It reads authorized lesson records from Les Sherpas and synchronizes them to the owner’s selected Google Calendar.

What the application does

Confirmed and dated pending lessons are represented as calendar events. Explicit cancellations remain visible with a [CANCEL] title and gray color. Manual calendar events are protected. Manually removed synchronized events are recorded so they are not automatically recreated.

Personal desktop application

The synchronizer runs on the owner’s computer. Google authorization happens in a supported browser through a desktop OAuth client. This documentation website has no account sign-in, lesson data, calendar access or authentication credentials.

The application requests read-only access to the calendar list and calendar properties (including event-label colors), plus event access for calendars owned by the authorizing account. Its write adapter restricts operations to the specifically configured calendar and does not delete events.

This project is not affiliated with, endorsed by, or operated by Les Sherpas or Google.
