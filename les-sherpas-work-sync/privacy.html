Privacy policy

Effective date: 3 October 2026. This policy covers the personal desktop synchronizer Les Sherpas Work Sync, maintained by Tomas Delon.

Data accessed and purpose

With the owner’s authorization, the application reads calendar identifiers and access roles, calendar events and event colors. It also reads lesson identifiers, statuses, subjects, student display names, lesson times and locations from the owner’s authenticated Les Sherpas account. These data are used only to reconcile lesson schedules with the configured calendar, preserve manual events and prevent unwanted recreation.

Local storage and retention

OAuth authorization tokens, source authentication state, configuration, diagnostic inventories and a synchronization ledger are stored locally with restrictive filesystem permissions. The ledger retains event mappings, synchronization history and deletion suppressions for as long as this installation is used. Suppression records do not expire automatically. Private diagnostic files and any owner-created backups may contain scheduling data.

Transfers and limited use

The application sends authorized lesson scheduling information to Google Calendar to create or update the owner’s events. It does not sell Google user data, use them for advertising or transfer them to third parties for unrelated purposes. The unattended runtime does not send scheduling data or credentials to AI services and does not use them to train AI models.

Les Sherpas Work Sync’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Owner control

The owner can stop the synchronizer and revoke its Google access at Google Account permissions. Revocation stops future access but does not remove already created calendar events or local files. The owner controls local data retention and may request guidance on removing their private installation data. The program never automatically deletes calendar events.

Documentation website

This static website does not collect lesson records, Google tokens or calendar contents. It contains no analytics or tracking scripts. Hosting is provided by GitHub Pages, whose infrastructure may process ordinary request metadata under GitHub’s privacy statement.

Contact and updates

Contact the maintainer through Tomas Delon’s contact page. Any material change to data practices will be reflected here before the corresponding application behavior is introduced.
